Research Methodology • Nottingham Trent University FYP (N1427018)

Methodology & System Architecture

Combining deterministic URL heuristic rules and machine learning to achieve transparent, secure, and explainable phishing detection for non-technical users.

Academic Research Aim & Question

Aim: To design, implement, and evaluate a website that detects phishing URLs by combining rule-based and machine-learning techniques, explaining its results clearly to non-technical users.

Research Question: Can URL rules combined with a Random Forest on URL-only features reach at least 0.90 phishing precision and recall on unseen URLs, with reasons non-experts can follow?

The 13 Transparent URL Heuristic Rules

Grounded in foundational studies (Zhang, Hong & Cranor, 2007; Mohammad, Thabtah & McCluskey, 2014) and the PhiUSIIL benchmark (Prasad & Chandra, 2024a), Phishield deterministically inspects 13 syntactic indicators without visiting destination pages:

  1. IP Address in Hostname (R1): Flags raw numerical IPv4, IPv6, or hex/octal representations bypassing standard DNS resolution controls.
  2. URL Length Analysis (R2): Catches bloated URLs (> 75 characters) engineered to conceal deceptive subdomains or evade mobile display boundaries.
  3. URL Shortening Service (R3): Detects link obfuscation services (e.g., bit.ly, tinyurl) used by threat actors to conceal target destinations.
  4. Deceptive "@" Symbol (R4): Flags authentication delimiters that trick web browsers into ignoring preceding authority text.
  5. Double Slash Redirection (R5): Detects consecutive slashes ('//') in path and query components indicating open redirects.
  6. Hyphens in Domain (R6): Identifies hyphenated patterns commonly found in lookalike brand domains.
  7. Subdomain Nesting Depth (R7): Evaluates multi-tiered subdomain stacking (3+ levels) mimicking legitimate corporate portals.
  8. Uncommon Web Port (R8): Detects non-standard ports (outside 80 and 443) designed to bypass perimeter reputation filters.
  9. Security Token in Hostname (R9): Catches misleading keywords ('https', 'http') embedded into hostnames to falsely imply encryption.
  10. Brand Name Impersonation (R10): Matches high-target financial and service brand names on unauthorized domain hosts.
  11. High-Abuse TLD (R11): Flags top-level domains statistically over-represented in disposable phishing infrastructure.
  12. Excessive Special Characters (R12): Identifies abnormally high delimiter counts used for token obfuscation.
  13. Punycode / Homograph Attack (R13): Detects Internationalized Domain Name prefixes ('xn--') and visual homoglyphs.

Machine Learning & Feature Engineering

Phishield extracts a 26-dimensional tabular feature vector purely from URL text (character counts, ratios, delimiter frequencies, and Shannon entropy).

Baseline Classifier

Logistic Regression model trained on tabular features to establish an empirical performance benchmark.

Production Classifier

Random Forest ensemble (100 estimators, max depth 15) achieving > 90% precision and recall with sub-millisecond offline inference latency.

Hybrid Decision Weighting: To prevent automation bias and provide resilient defence against single-model adversarial evasion, the final assessment combines the 13 heuristic rules (40% weight) and the Random Forest probability (60% weight).
